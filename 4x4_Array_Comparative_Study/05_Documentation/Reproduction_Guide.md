# Reproducing the 150 GHz comparison

1. Open the selected `01_CST_Project/Final_4x4/Final_4x4.cst` in CST Studio Suite 2024. Keep its same-named companion directory next to the project. For a fresh calculation, copy both to a separate writable working location and run the time-domain solver without changing the stored physical settings.
2. Select the raw complex S11 trace under **1D Results → S-Parameters**, or read `CST_50ohm.s1p` for the independently renormalised 50 Ω trace. The postprocessor converts the solved modal reference using (Z_{in}=Z_{ref}(1+Γ)/(1-Γ)), followed by (Γ_{50}=(Z_{in}-50)/(Z_{in}+50)). Bandwidth is the contiguous −10 dB interval containing 150 GHz. An unmatched working point has no such interval.
3. Check **1D Results → Power → Excitation [1]** and the 150 GHz Farfields node. Radiation efficiency is (P_{rad}/P_{acc}). Total efficiency at 50 Ω multiplies it by (1-|Γ_{50}|^2). Peak realized gain and +Z realized gain use the full-sphere peak and the fixed θ=0° sample respectively. Compare **Directivity**, **Realized Gain**, and the 150 GHz surface-current monitor. E and H cuts are respectively YZ and XZ, combined from the positive and negative azimuths.
4. To reproduce the generated geometry, use the CST installation’s Python with `04_Automation/Run_4x4.py <new-case-name> '<changes as JSON>' --detail`. Use a new case name for new settings. The solver saves the real CST project, then reopens it and exports native angular and power data. The optional `--extract` switch retrieves previously solved results. Versions and port settings are in the final Model History file.
5. Run `04_Automation/Extract_Results.py Final_4x4` with Python and installed NumPy and Matplotlib to regenerate source-derived tables and plots. The script reads the original Round 1 1×2 exports at the sibling project path. For a standalone review copy, keep the same baseline hierarchy and companion directory. Use the saved [parameter and mesh verification](../02_Simulation_Results/Verification/) to reproduce comparisons without altering a source archive.

## Reproducing from the public repository

1. Download both [the final 4×4 archive](../Artifact_Manifest.md) and [the 82.99% baseline 1×2 archive](../../Large_Artifacts/ARTIFACT_DOWNLOAD_GUIDE.md). Verify their published SHA256. Extract the former under the study directory and the latter at the repository root, preserving the internal folders.
2. Set `CST_INSTALLPATH_2024` to your CST installation if it differs from the original project installation. For custom layout, set `TELE9782_BASELINE_DIR` to the extracted Round 1 directory containing parameters.json and native exports. Keep the model beside its companion directory.
3. In a disposable working copy, run the installed CST Python with `04_Automation/Verify_Native.py Final_4x4` to compare S11, ZRef and powers directly against original exports. To regenerate the table and original plots, run `python 04_Automation/Extract_Results.py Final_4x4` with NumPy and Matplotlib. Review scripts that write data in the study directory before invoking them.
4. Run `python 04_Automation/Plot_Handover_Figures.py` with Matplotlib to regenerate the four derived figures from the archived CSV and geometry JSON without CST. To regenerate the initial geometry, follow the builder or use the initial trial parameter file and CST ModelHistory. The initial binary remains local because its schematic metadata embeds a user profile path.
